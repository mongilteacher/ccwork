1. 컴포넌트 의존성 그래프

이 앱의 핵심은 렌더 트리와 데이터 의존성이 서로 다르다는 점입니다. NoteList·NoteEditor는 App → Layout을 거쳐 렌더되지만(실선), 데이터는 useNotes()로 NotesProvider에서 직접 당겨옵니다(점선). props로는 선택 상태와 콜백만 내려갑니다.

3. 상태 흐름 — 노트 저장 1회 왕복

mutation은 api 호출 성공 후 로컬 배열만 갱신하고 재fetch하지 않습니다. 타임스탬프는 서버가 아니라 api 계층에서 주입됩니다. 실패 시 api가 던진 에러를 Context는 잡지 않고 그대로 전파하며, 컴포넌트가 console.error로만 처리합니다. 

sequenceDiagram
  autonumber
  actor U as 사용자
  participant E as NoteEditor
  participant C as NotesContext
  participant A as api/notes.ts
  participant S as json-server

  U->>E: 저장 클릭
  E->>E: title.trim() 검사
  E->>E: setSaving(true)
  E->>C: createNote(title, content)
  C->>A: api.createNote({ title, content })
  A->>A: createdAt · updatedAt 주입
  A->>S: POST /notes

  alt res.ok
    S-->>A: 201 + Note
    A-->>C: Note
    C->>C: setNotes(prev => [...prev, newNote])
    C-->>E: resolve
    E->>E: onDone()
    C-->>U: 목록 리렌더
  else 실패
    S-->>A: 4xx / 5xx
    A-->>C: throw Error('Failed to create note')
    C-->>E: reject (잡지 않고 전파)
    E->>E: console.error(e)
  end

  E->>E: setSaving(false)

현재 실패 경로는 콘솔에만 기록되고 화면에는 아무 변화가 없습니다. 사용자에게는 "저장이 안 됐다"는 신호가 전혀 없다는 점을 유의하세요.

4. 초기 로드 흐름

mutation과 달리 초기 로드 실패만 Context가 error state로 흡수해 화면에 렌더합니다. NoteList는 이 세 상태를 early return으로 분기합니다. 

graph LR
  Mount["NotesProvider 마운트
loading = true"] --> Fetch["api.fetchNotes()"]
  Fetch -->|성공| Set["setNotes(data)"]
  Fetch -->|실패| Err["setError(e.message)"]
  Set --> Fin["finally: setLoading(false)"]
  Err --> Fin
  Fin --> Render{"NoteList 분기"}
  Render -->|loading| L["로딩 중..."]
  Render -->|error| E2["오류: ..."]
  Render -->|"length === 0"| Z["노트가 없습니다"]
  Render -->|그 외| List["NoteItem 목록"]

5. state 소유권

서버 데이터는 오직 Context만 소유합니다. 컴포넌트 로컬 state는 UI 전용 (폼 입력값, 제출 중 플래그, 선택 상태)뿐입니다.

소유자 state 성격 소비처
NotesContext notes 서버 데이터 NoteList, NoteEditor
NotesContext loading · error 초기 로드 상태 NoteList
App selectedNoteId 선택 상태 props → NoteList, NoteEditor
App isCreating 모드 분기 props → NoteEditor
NoteEditor title · content 폼 입력값 자기 자신
NoteEditor saving 제출 중 플래그 자기 자신 (버튼 disabled)
NoteItem — state 없음 순수 표시 컴포넌트
