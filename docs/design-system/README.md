# 디자인 시스템 — The Digital Atelier

Stitch가 제공한 노트 앱 디자인 시스템을 이 저장소의 **정본**으로 정착시킨 문서 묶음이다.
앞으로의 모든 스타일 작업은 이 폴더를 기준으로 한다. `CLAUDE.md` 「스타일링」은 여기를 가리키는 요약일 뿐이다.

> **적용 상태 표기**
> ✅ = 현재 코드에 이미 반영됨 / 🚧 = 정본이지만 코드는 아직 구버전

## 문서 관리 규칙

이 폴더를 나눠 둔 이유는 파일을 예쁘게 정리하기 위해서가 아니라 **드리프트를 막기 위해서**다. 아래 5개는 문서를 수정할 때마다 지킨다.

1. **hex 값은 `foundations.md`에만 존재한다.** 다른 파일은 토큰명(`surface_container_low`)으로만 참조하고, 절대 `(#f1f4f6)`처럼 병기하지 않는다. 팔레트 12개 토큰이 본문 곳곳에 hex로 복사되면 색을 한 번 바꿀 때 파일 5개를 뒤져야 한다.
2. **Do/Don't는 각 파일이 자체 보유한다.** 규칙 바로 옆에 있어야 의미가 있으므로 이 README에 몰아넣지 않는다.
3. **`CLAUDE.md`는 이 README 하나만 가리킨다.** 진입점을 여러 개 만들면 어느 파일이 정본인지 흐려진다.
4. **`migration.md`는 만료 문서다.** 영구 규칙과 절대 섞지 않는다. 로드맵 체크박스가 다 차면 파일을 삭제하고 위 표에서 행을 지운다.
5. **파일명은 kebab-case.** 기존 `docs/features/tag/` 관례와 맞춘다.

## 1. 크리에이티브 방향

**북극성: The Curated Archive (큐레이션된 아카이브)**

일반적인 "지식 베이스" 템플릿이 아니라 **디지털 아틀리에**의 철학을 따른다. Notion의 실용성에서 출발하되 실행은 **Soft Minimalism**의 영역으로 옮긴다. 노트 하나하나를 데이터가 아니라 개인 박물관의 소장품처럼 다룬다.

"제네릭 SaaS" 룩을 깨는 두 축은 **의도적 비대칭**과 **톤의 깊이**다. 콘텐츠를 테두리 있는 상자에 가두지 않고, 정교한 중성 톤 레이어 위에 띄운다. 타이포그래피가 숨 쉴 공간을 주고 정보가 주인공이 되게 한다. UI는 학습이라는 "조용한 순간"과 절대 경쟁하지 않는다.

### Do

- 여백을 **구조 요소**로 쓴다. 애매하면 마진을 늘린다.
- 위계는 색이 아니라 **톤 차이와 타이포 스케일**로 만든다.
- 액센트 컬러는 의도가 있는 행동에만 아껴 쓴다.

### Don't

- 정보 밀도를 채우려고 컨테이너를 늘리지 않는다.
- 장식만을 위한 UI 요소(구분선, 아이콘, 배경 패턴)를 넣지 않는다.
- 기능적 명확성이 없는 아이콘을 쓰지 않는다. 이 시스템은 **타이포 주도**다.
