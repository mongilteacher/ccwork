# Knowledge Token (태그 칩)

주제 태깅용 커스텀 칩(`#javascript`, `#design`). 토큰 정의는 [`../foundations.md`](../foundations.md) 참조.

## 🚧 규격

| 항목   | 값                          |
| ------ | --------------------------- |
| 배경   | `surface_container_highest` |
| 텍스트 | `on_surface_variant`        |
| 라운드 | `full`                      |
| 테두리 | 없음                        |

칩은 팔레트에서 가장 밝은 컨테이너 톤을 쓴다. 액센트(`tertiary`)를 칩에 쓰지 않는 게 핵심이다 — 태그는 메타데이터지 행동이 아니다.

## 태그 기능과의 관계

[태그 기능 명세서](../../features/tag/spec-fixed.md)의 칩 UI는 **이 규격을 따른다.** 해당 명세서가 "시맨틱 토큰 사용, 원시 Tailwind 색상 금지"라고 적은 부분의 구체적 실체가 위 표다.

아직 구현되지 않은 유일한 컴포넌트이므로, **처음부터 정본대로 만들 수 있는 유일한 기회**다. 다른 컴포넌트처럼 마이그레이션을 거칠 필요가 없다.

## Do

- `full` 라운드 + 무테두리를 지킨다.
- 텍스트는 `label-md`가 아니라 본문 계열로 둔다 — 태그 값은 사용자가 쓴 내용이지 시스템 라벨이 아니다.
- 삭제 버튼이 붙는 경우 칩 안에서 Ghost 스타일로 처리한다.
- 칩 여러 개는 `spacing.1` 간격으로 나열한다.

## Don't

- 칩에 테두리를 넣지 않는다.
- 칩 배경에 `tertiary`나 액센트 계열을 쓰지 않는다.
- 태그마다 다른 색을 자동 배정하지 않는다 — 이 시스템은 단일 액센트이고, 태그는 색으로 구분되지 않는다.
- 칩을 각진 모서리(`rounded-md`)로 만들지 않는다. `full`이 규격이다.
